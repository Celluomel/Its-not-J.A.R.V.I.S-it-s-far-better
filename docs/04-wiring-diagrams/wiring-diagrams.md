## 🎯 Key Architectural Patterns Identified

### 1. Event-Driven Architecture
All major state changes flow through cognitive event bus, preventing tight coupling between modules.

### 2. Persistent State Layer
Critical state (goals, identity cursor, episodic memories) written to disk between sessions for continuity.

### 3. Multi-Level Memory
- Short-term: In-memory dictionaries
- Working memory: ai_identity.context_window  
- Episodic: SQLite + FAISS in semantic_memory.db
- Procedural: Embedded in goals.json structure

### 4. Hierarchical Abstraction
- Low level: Raw sensor data (vision/audio)
- Mid level: Perception events (features/objects)  
- High level: Goals/pressures/motivations
